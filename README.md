# ASS — Interactive Image Console

The exact generated paranormal console image is now the primary UI surface.

Controls are registered directly over the artwork:
- upper/lower regions of each red number drum change Amount, Smell, Sound
- red ASSESS dial classifies
- NEW ASSESSMENT resets
- SHARE RESULT invokes native sharing when available
- CLASSIFICATION ARCHIVE button area toggles music
- live score digits and containment report render inside the image composition
